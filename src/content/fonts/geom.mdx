Geom is a geometric sans serif by Thanos Poulakidas, a designer based in Athens. It started as
an open-source project on GitHub in 2022 and was added to Google Fonts in November 2025. It ships
as a single variable file with a weight axis from 300 to 900, a matching italic, and Greek
alongside Latin and Latin Extended.

The shapes are built from circles and straight strokes, but the spacing is kept practical rather
than airy, so it reads well in interface text as well as in big headlines. The matching italic
covers the full weight range, so emphasis doesn't mean loading a second family. If DM Sans feels a little soft for what you're building, Geom is the crisper,
more technical neighbour.
