Inter Tight is a specialized version of Rasmus Andersson's Inter, released through Google Fonts
in 2022. It keeps the family's familiar sans serif character but tightens the spacing for display
use. The variable weight axis runs from 100 to 900, with both upright and italic styles.

Reach for it when a large headline needs to feel compact: a landing-page introduction, a project
title, or a short editorial heading. Regular weight gives those settings a restrained voice,
while heavier weights make a more assertive statement.

The tighter spacing is a display choice. For long passages or dense interface text, compare it
with the original Inter in the reading preview before choosing. Crimson Text offers a contrasting
serif for body copy, and Inconsolata adds a distinct voice for code and technical details.
